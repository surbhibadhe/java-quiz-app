# Java Quiz App

A simple Quiz Application built in Java while learning and practicing Core Java concepts.

## About

This project is being developed as a learning project by following a Java Quiz App tutorial and implementing the concepts along the way.

## Tech Stack

* Java
* Core Java

## Features

* Quiz questions
* Multiple-choice answers
* Score calculation

## Status

🚧 Work in Progress

More features and improvements will be added as the project develops.

## How to Run

1. Clone the repository.
2. Open the project in your Java IDE.
3. Compile and run the main Java file.
